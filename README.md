# Smart Job Portal System

A console-based Java Smart Job Portal System using OOP concepts. Currently supports user registration, login, job listing, job search, job application flow, and admin job posting functionality.

## Features

* User Registration
* User Login
* View Available Jobs
* Search Jobs by title, company, or location
* Apply for Jobs
* View My Applications
* Admin Add Job Feature
* Console-based Java Application
* OOP-based implementation using classes and objects

## Tech Stack

* Java
* OOPs
* GitHub
* ArrayList Collections Framework
* MySQL/JDBC planned for future enhancement

## How to Run

```bash
javac src/Main.java
java -cp src Main
```
