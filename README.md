# Smart Job Portal System

## Overview
A console-based Job Portal System developed using Java and Object-Oriented Programming concepts.

## Features
- User Registration
- User Login
- View Jobs
- Search Jobs
- Apply for Jobs
- Admin Job Management
- Database Connection Layer

## Technologies Used
- Java
- OOP
- Git
- GitHub
- MySQL (Planned)
- JDBC (Planned)

## Project Structure
src/
├── User.java
├── Job.java
├── Application.java
├── UserService.java
├── JobService.java
├── AdminService.java
├── DBConnection.java
└── Main.java
